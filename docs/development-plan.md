# 分阶段开发与提交计划

每个阶段都形成一个能单独解释和回退的 Git 提交。

1. `docs: define course project architecture`
   - 明确范围、技术栈和主流程。
2. `feat: implement after-sales MCP tools`
   - 实现订单、物流和退款资格查询及测试。
3. `feat: add MaxKB knowledge base and prompt`
   - 增加知识文档、系统提示词和接入步骤。
4. `test: add evaluation cases`
   - 用固定问题验证知识问答、工具路由和隐私校验。
5. `docs: prepare deployment and defense guide`
   - 整理一键部署、演示脚本和答辩要点。
