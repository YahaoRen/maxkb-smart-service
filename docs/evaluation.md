# 评测说明

本项目把评测分成两层，避免用一个模糊的“感觉回答不错”代替验证。

## 1. 业务规则自动评测

`evaluation/tool-cases.json` 固定了模拟日期、工具参数和期望字段。运行：

```powershell
.\.venv\Scripts\python.exe scripts\evaluate_rules.py
```

这层不调用大模型，专门验证订单校验、隐私保护、物流状态和退款规则。任何用例失败都会返回非零退出码，因此可以放进持续集成。

2026-10-08 本地基线结果：`9/9` 通过，规则准确率 `100.0%`。

## 2. MaxKB 端到端评测

`evaluation/maxkb-manual-cases.md` 验证三个大模型相关能力：

1. 能否区分知识库问题和工具问题；
2. 缺少参数时能否正确追问；
3. 能否忠实解释知识片段和工具结果。

端到端结果会受所选模型、提示词和知识库分段影响，所以应在最终模型配置确定后记录结果，不能用离线规则评测冒充大模型评测。
