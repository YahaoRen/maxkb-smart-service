# 模拟订单数据

以下数据全部为课程演示用途，不对应真实用户。

| 订单号 | 手机号后四位 | 状态 | 推荐演示问题 |
| --- | --- | --- | --- |
| `DD202610080001` | `5678` | 已发货 | “我的快递到哪里了？” |
| `DD202610010002` | `2468` | 签收 3 天 | “买错了，可以七天无理由退货吗？” |
| `DD202609100003` | `1357` | 签收超过 7 天 | 对比“不喜欢了”和“屏幕损坏”两种原因 |
| `DD202610080004` | `8866` | 待发货 | “还没发货，现在退款能退多少钱？” |

## 隐私校验演示

使用正确订单号但错误的手机号后四位，例如 `DD202610080001 + 0000`。工具应只返回“订单不存在或手机号后四位不匹配”，不能暴露订单是否真实存在。
